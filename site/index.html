Your browser windows, kept the way you left them.

Windrow saves every window as a session the moment it changes — tabs, groups and all. Close a window by accident, or crash, and it is still there to restore. Everything stays in your profile. No account, no telemetry, no subscription.

What it does today

Windrow runs as a Chrome MV3 extension. This is the M3-era build — a working core, not a mockup — so the list is deliberately short.

Capture

Sessions save themselves

Every window is a session, written on tab, group, and window events. There is no “save” button to forget.

Groups

Tab groups come back intact

Names, colors, and membership are captured through chrome.tabGroups and rebuilt on restore.

History

Every change is recoverable

Per-session snapshots are pruned to a limit, so restoring the wrong version is not a one-way door.

Surfaces

Side panel and full tab

The side panel stays live while you browse. The full-tab manager gives you a three-pane workspace with drag-and-drop between sessions.

Memory

Native discard

Uses chrome.tabs.discard rather than rewriting URLs through a CDN suspender, so pages keep their real address.

Portability

Your data leaves with you

Export plain JSON or a passphrase-encrypted file. Import a Windrow backup, a OneTab export, or just a list of URLs. No lock-in.

Privacy

Nothing leaves the browser

No host permissions at install. No account, no analytics. Optional permissions are requested only when you use the feature.

Why another one

Session managers tend to put restoration, history, and sync behind a subscription. Windrow takes the opposite position.

01

Free means free

No paid tier above it, no trial, no feature held back. MIT-licensed, so the whole thing can be forked if this project ever stops being useful.

02

Local by default, sync by choice

The current build stores everything in IndexedDB and never makes a network request. When sync lands, it will talk to a server you run, with encryption on your device before anything is sent.

03

Ask for less

The manifest requests no host permissions at install. history and bookmarks are optional and off until you turn them on.

Install from source

There is no store listing yet. You need Node 22+ and Chrome 116 or newer. The build runs locally; no account or key is involved. 

# clone and build
git clone https://github.com/abominox/Windrow.git
cd Windrow
npm ci
npm run build

Verify it first if you like: npm test runs 46 unit tests, npm run typecheck runs the compiler.

  1. Open chrome://extensions.
  2. Turn on Developer mode (top right).
  3. Choose Load unpacked.
  4. Select the dist/ folder.
  5. Pin Windrow, then open the side panel.
