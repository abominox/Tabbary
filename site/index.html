A local-first tab and session manager

Your tabs,

Windrow is a tab manager. It captures the tabs you are working on — across groups and windows — as a session, continuously and without a save button. Close something by accident, or crash, and it is still there.

One tab library, four ways in

The surfaces share state, so moving between them is free. Each one shows the same tabs and sessions; only the amount of space changes.

  • pop PopupCurrent window, recent sessions, search. click icon
  • side Side panelStays open beside the page you are reading. alt + a
  • tab Full tabThree panes: tags, sessions, detail. Drag between them. alt + s
  • win Dedicated windowA compact two-pane view for a second screen. from the popup
  • tag Tags & bookmarksManagement views for the things sessions accumulate. alt + t / b
03

The boring promises, kept

No growth loop, no account system, no telemetry. These are properties of the build, not policy statements.

No host permissions at install. Windrow cannot read the page you are on. Tab access is scoped to Chrome's tab metadata, which is what a session manager needs and nothing more.

History and bookmarks are optional. They are requested only when you use the feature that needs them, and can be revoked afterwards without uninstalling.

Sync is ciphertext-only. Sessions are encrypted on this device with a key the server never sees. You can point it at the hosted instance or run your own — the server is a single Node process with no dependencies. Because it cannot read the blobs, there is no password reset.

Export is plain JSON. A backup you can read, diff, and script against — and an encrypted variant if you would rather it were not readable.

Install from source

Chrome 116+. No account, no key, no store listing yet. About a minute, once.

# clone and build
git clone https://github.com/abominox/Windrow.git
cd Windrow
npm ci
npm run build

Verify first if you like: npm test runs 195 unit tests, npm run test:server exercises the sync server.

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked.
  4. Select the dist/ folder.
  5. Click the Windrow icon.
